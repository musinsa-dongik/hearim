# 헤아림 데일리 템플릿

아래 형식을 따라 작성한다. 섹션 순서를 지킨다.

`````markdown
## 헤아림 데일리: YYYY-MM-DD (요일)

### 오늘의 키워드

[당일 작업하며 접한 핵심 개발 용어/개념을 나열한다. 3-5개.]

- **[용어/개념 1]**
- **[용어/개념 2]**
- **[용어/개념 3]**

### 배경

[대외비 없이 1-2문장으로 상황 설명. "기존 목록 페이지에 필터/검색을 붙이는 작업에서..." 수준]

---

### 배움 카드 (Concepts)

#### 1. [개념/패턴 이름]: [내 경험과 연결한 부제]

[문제 상황 -> 시도 -> 발견 순서로 서술. 3-5문장.]
[왜 이 방법을 택했는지, 대안은 뭐였는지, 그 대안을 왜 안 택했는지.]

**코드:**
```typescript
// Before: 뭐가 문제였는지 주석으로 설명
// After: 어떻게 바꿨는지
// 내부 컴포넌트명은 일반화 (예: MyInternalComponent -> ListComponent)
```

**언제 쓰는가 / 언제 안 쓰는가:**
- [적용 조건]
- [반대로 맞지 않는 경우]

> 참고: [공식 문서 또는 권위 있는 레퍼런스 링크]

---

#### 2. [개념/패턴 이름]: [부제]

[동일 구조. "내가 부딪힌 문제"로 시작.]

---

### 정리

| 상황 | 판단 기준 | 선택 |
|------|----------|------|
| ... | ... | ... |

### 이전 학습 질의 연결

- **[이전 질의 주제]** (M/DD 질의): [오늘 어떻게 답을 찾았는지, 또는 부분적으로 해소된 내용]

> 이전 헤아림이 없으면 이 섹션을 생략한다.
> 이전 질의와 직접 연결되지 않더라도, 관련 주제가 오늘 등장했으면 언급한다.

### 더 알아볼 것

- [ ] [구체적 도구/패턴명을 포함한 질의 -- "다음에 뭘 해야 하는지"가 명확하도록]
- [ ] [비교 대상이 있으면 명시 (A vs B), 트레이드오프 관점의 질문]

### 참고 자료

- [제목](URL)
- [제목](URL)

---

[메타인지적 관점에서 오늘의 학습을 정리. 성장 방향 제시. 구체적 다음 단계 제안 포함. 2-3문장.]
`````

## 톤 규칙: "정적 설명" 금지

교과서적 서술 대신, 경험 기반 서사로 작성한다.

**금지 (정적):**
> `useInfiniteQuery`의 queryKey가 바뀌면 자동으로 refetch된다.

**권장 (경험 기반):**
> 필터 탭을 눌렀는데 목록이 안 바뀌어서 왜인지 살펴봤다. queryKey가 `["dailies"]`로 고정되어 있어서 filter 값이 바뀌어도 React Query가 "같은 데이터"로 인식한 것이었다. queryKey에 `[filter, search]`를 넣자마자 탭 전환 시 자동으로 첫 페이지부터 다시 로드되었다.

**판별 기준:** "이 문장을 GPT/Claude에게 물어봐도 같은 답이 나오는가?" -> YES이면 정적 설명이므로 내 경험으로 바꿔야 한다.

## 대외비 제거 규칙

출력물에서 다음 항목을 반드시 제거한다:
- Jira 티켓 번호 (GPRD-xxxx, PROJ-xxxx 등)
- Git 커밋 해시 (`68fd9f3d6` 등)
- 줄 수, 파일 수 (`13개 파일, +772/-103줄` 등)
- 내부 서비스명, 프로젝트명, 팀명
- 내부 컴포넌트/함수명은 일반화 (ReviewGalleryFilter -> LegacyFilter 등)

유지하는 것:
- "내가 부딪힌 문제 -> 시도 -> 발견" 서사
- 판단 근거, 트레이드오프, 반례
- 코드 패턴 (일반화된 형태)
- 공식 문서 링크

## 작성 기준

- 배움 카드: 최소 2개, 최대 4개
- 각 카드는 반드시 "내 경험에서 시작"해야 한다 -- 교과서 정의로 시작하지 않는다
- 공식 문서 링크는 개념당 최소 1개
- "정리" 표는 오늘 배운 판단 기준을 한눈에 보여주는 용도
- "더 알아볼 것"은 구체적 도구명/패턴명을 포함하여 다음 행동이 명확하도록
- 이전 헤아림의 "추가 학습 질의"와 오늘 배운 것을 연결
- "헷갈린다", "추가 학습 필요" 표현 허용
- 작성 시간 목표: 10분 이내
